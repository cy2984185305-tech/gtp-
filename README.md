# CardHub 卡密兑换网站 MVP

这是第一版前端原型：简洁白色风格，包含商品展示、商品详情、卡密兑换、兑换结果。

## 运行
1. 安装 Node.js 18+。
2. 在项目目录运行 `npm install`
3. 运行 `npm run dev`
4. 浏览器打开 http://localhost:3000

## 演示
兑换页面输入 `DEMO-VALID` 可看到成功页面。
